# Python Fundamentals

Core Python and object-oriented programming practice — the groundwork for everything built on top of it in this repo and beyond.

## What this covers

- Python core syntax, data structures, and control flow
- Object-oriented programming — classes, inheritance, encapsulation, and design fundamentals
- Practice problems and small exercises worked through while building a solid Python foundation

## Why it's here

Before building API-driven tools and LLM integrations (see the other folders in this repo), solid command of Python fundamentals and OOP is what makes that code maintainable and extensible rather than one-off scripts. This folder is the record of that groundwork.


## How to run

```bash
cd python-fundamentals
python <script_name>.py
```

Each script is self-contained and runnable independently.
