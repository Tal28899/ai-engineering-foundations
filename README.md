# AI Engineering Foundations

Foundational projects built while developing core skills for **RAG and AI Automation Engineering** — covering Python/OOP fundamentals, API integration, error handling, and LLM API usage.

This repo documents the building-block skills that sit underneath more advanced RAG and agentic AI systems, before those systems get their own dedicated repos.

## Structure

| Folder | What's inside |
|---|---|
| [`python-fundamentals/`](./python-fundamentals) | Core Python and OOP practice — syntax, data structures, and object-oriented design fundamentals |
| [`cli-weather-app/`](./cli-weather-app) | A CLI tool that fetches live weather data via a public API |
| [`cli-llm-chatbot/`](./cli-llm-chatbot) | A CLI chatbot with conversation history, built on the Groq LLM API |

## Tech stack

Python · Requests · python-dotenv · Groq AP

## Setup

Each subfolder has its own README with specific setup and run instructions. General requirements:

```bash
git clone https://github.com/Tal28899/ai-engineering-foundations.git
cd ai-engineering-foundations
pip install -r requirements.txt
```
